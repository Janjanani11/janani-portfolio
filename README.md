# Janani M — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — responsive professional styling
- `script.js` — mobile navigation, reveal animations and current year
- `resume.docx` — resume used for the portfolio

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository, for example `janani-portfolio`.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Your portfolio will be available at:
   `https://YOUR-USERNAME.github.io/janani-portfolio/`

## Before publishing
Replace the LinkedIn placeholder with your actual LinkedIn profile URL if you want to add it.
